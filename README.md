# ecommerce-review-analysis
customer review and product analysis using SQL, Python and Power BI
## Project Overview
This project analyzes the reviews and rating given by the customers in order to understand customer satisfaction, common customer complaints and product performance.
## Tools and Technnologies
- SQL (MySQL)
- Python
- pandas
- Matplotlib
- Power BI
- GitHub
## Analysis Performed
### SQL Analysis
- Basic Exploration
- Average rating by department
- Most Reviewed Product Classes
- Overall recommendation rate
- Review by age group and Product class
- Rating vs Recommendation
- Complaint analysis based on complaint theme and low rated reviews
- Poor Satisfaction rate
- Low Rated product's reviews are more helpful for customers
### Python Analysis
- Data cleaning
- Review text cleaning
- Negative review analysis
- Complaint theme identification
- Complaint analysis by clothing class
